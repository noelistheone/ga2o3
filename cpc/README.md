# Differentiable defect-thermodynamic sandbox

Code and reproduction data for **A differentiable defect-thermodynamic sandbox
for dopant activation prediction**.

The sandbox maps incorporated dopant concentration and preparation conditions to
frozen defect inventories, low-temperature charge balance, and Hall carrier
response. Implicit differentiation propagates learning signals through the
coupled physical roots. The implementation supports inventory learning,
variable-temperature donor activation, and property-directed acquisition of
missing energetic labels.

All Supplementary Material file paths and commands are relative to **`cpc/`**.
The repository includes the curated tables, saved parameters, numerical records
and host atomic coordinates used by those commands. The 2026-10-31 article
snapshot is indexed by `cpc_distribution_manifest_20261031.json`; its
`repository_release` field identifies the public packaging revision. No GPU is
required.

## Installation and saved-result reproduction

Use Python 3.11:

```bash
cd cpc
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/verify_release.py
python scripts/verify_metrics.py
python scripts/summarize_submission_validation.py
python scripts/summarize_gradient_paths.py
```

The release check verifies each published file against its SHA-256 digest.
Run it before regeneration, since regeneration can change serialization and
runtime records. The three scientific summaries recompute **331**, **74** and
**448** checks from the archived per-observation predictions, fit records and
gradient coordinates. They run without KROGER, model retraining or access to
the original research workspace.

`source_data/input_provenance.json` records checksums under the released paths
and retains the original source-hash ledger as historical provenance. The
historical paths in that ledger identify where the data originated; the
commands below use the released paths.

## Prepare the energetic input

```bash
python scripts/prepare_kroger_input.py
python examples/predict_example.py --element Si --dose 1e18
```

The preparation command downloads the KROGER input from its original repository,
verifies its pinned checksum and extracts it locally. The example returns a
carrier prediction and parameter derivatives at explicit demonstration
coordinates. A mathematical Fermi-integral lookup table, generated by quadrature
without experimental labels, is included at
`research/data/physics_reference/fermi_half_v1.npz`. Its generator is
`research/scripts/trainable_sandbox_20261017/phase15_build_fermi.py`.

## Fresh training, acquisition and prediction

These are the Supplementary Sec. S8 commands, using the supplied input tables:

```bash
python scripts/sandbox_workflow.py fit --kind inventory \
  --input source_data/validation_room_inputs.csv \
  --held 10.1007/s40843-022-2167-x --output runs/inventory
python scripts/sandbox_workflow.py acquire --element Si \
  --budget 2 --output runs/energy_si
python scripts/sandbox_workflow.py predict \
  --model runs/inventory/model.json \
  --input examples/query_inputs.csv --output runs/prediction.csv
```

Inventory fitting excludes the target related-source group, uses a fixed
response-prior weight of 0.1, and optimizes from two prescribed fresh starts.
Each output contains the input checksum, protocol, every optimizer start,
convergence status, fitted coordinates and held-out predictions. Choose a new
output directory for each completed fit. These runs demonstrate fresh fitting;
the article's full outer-fold scores are reconstructed from `source_data/`.

The physical predictor uses seven fields:

| Field | Meaning / units |
| --- | --- |
| `element` | `Si` or `Sn` |
| `incorporated_cm3` | Incorporated chemical dopant concentration, cm^-3 |
| `Tobs_K` | Measurement temperature, K |
| `growth_T_C` | Growth temperature, degrees C |
| `H_known` | Boolean; whether the hydrogen input is supplied |
| `H_cm3` | Hydrogen concentration, cm^-3; zero when `H_known=False` |
| `scenario_pO2_atm` | Explicit oxygen-pressure scenario, atm |

For your own inventory training table, add `target` (log10 Hall concentration in
cm^-3), `family` (publication ID), `sample_id`, `related_cluster` and
`scenario_weight`. The value passed to `--held` identifies the excluded
`related_cluster`. Source IDs and observed responses do not enter the physical
prediction interface. Unreported hydrogen selects an explicit zero-H scenario.

For a fresh thermal fit:

```bash
python scripts/sandbox_workflow.py fit --kind thermal \
  --input source_data/validation_thermal_inputs.csv \
  --held 10.1063/5.0101132 --derivative IFT --output runs/thermal_ift
```

Change `--derivative` to `FD` and use `runs/thermal_fd` to compare the
finite-difference derivative path with the same starts and optimizer settings.
Thermal input tables use the seven physical fields plus `target`, `family`,
`sample_id` and `kind` (`RT` for room-temperature endpoints); `--held` excludes
the entire publication. The thermal instance uses the effective donor-ionization
closure with `rH=1` and the documented temperature/publication split.

The acquisition command trains a 64-tree Extra Trees prior on other dopants,
calibrates covariance inflation on training-element exclusions, selects two
masked catalogue labels on 12 design conditions, and evaluates eight separate
virtual query conditions. Use `--element Sn --output runs/energy_sn` for Sn.
This is retrospective acquisition of published energetic labels; no electrical
labels enter selection. The full historical selected-prior comparisons,
covariance controls and 32 random trajectories are supplied in `source_data/`.

## Saved-model replay and numerical checks

After preparing KROGER:

```bash
python scripts/replay_inventory.py
python scripts/sandbox_workflow.py predict \
  --model verification/cpc_workflow/inventory_ift/model.json \
  --input examples/query_inputs.csv --output runs/saved_model_prediction.csv
python scripts/benchmark_cpc.py --output runs/numerics
python scripts/benchmark_gradient_paths.py --output runs/gradient_paths
```

The replay reconstructs **98** archived room-temperature predictions from the
original fitted coordinates and scenario table, with measured responses removed
before each solver call. Both parameter directories are included under
`research/results/predictive_redesign_20261019/proposal_followup_20261021_v1/`:
`overlay_nH_controls_v1/fits/` and `constrained_block_v1/primary_fits/`.

The numerical benchmark covers 32 energetic-Jacobian settings, 1,504 coordinate
checks and eight independent nested-bracketing roots. The gradient-path
benchmark separates preparation-inventory and cold-occupation sensitivities
over 208 coordinate/condition pairs and two finite-difference steps (832 scalar
comparisons). The original submission records are in `verification/cpc_numerics/`
and `verification/gradient_paths_20261031/`; timings depend on hardware.

The archived 14,896- and 256-check historical audit reports reside under
`research/results/predictive_redesign_20261019/proposal_followup_20261021_v1/`
in `independent_audit_v1/` and `additional_independent_audit_v1/`. The 2,083-check
report is under `research/results/predictive_redesign_20261019/targeted_closure_20261021_v1/independent_audit_v1/`.
These are original recorded results. The runnable checks listed above verify
the curated article release without rebuilding every historical experiment.

## Source layout and upstream input

`scripts/sandbox_workflow.py` is the portable training/prediction/acquisition
entry point. `research/src/sandbox/` contains the physical solvers, charge
statistics, transport and implicit derivatives. The original stage scripts in
`research/scripts/` preserve the research implementations; some historical
launchers refer to larger development datasets. The commands documented here
use the published inputs and the separately prepared KROGER catalogue.
